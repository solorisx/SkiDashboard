Include the CSS files in your template's extra_head block: - activity-cards.css (main component styles) - common-layouts.css (layout utilities) - Plus any existing component files (badges.css, progress-circles.css) 2. Include the JS files in your extra_js block: - common-utils.js (global utilities) - activity-cards.js (activity-specific functionality) 3. Use the CSS classes: - .activity-card for main activity containers - .stats-card for statistic displays - .card-body-flex with .flex-grow-1 and .mt-auto for flexible layouts - .page-header, .stats-overview, .card-grid for page structure 4. HTML structure: - Use data attributes for completeness cards: data-activity-id, data-ski-area-id - Include proper ARIA labels and tooltip attributes - Structure cards with flexible body layout 5. JavaScript integration: - The ActivityCardManager will auto-initialize - Override getActivityDataForMap method for custom map data - Use CommonUtils for standard functionality Key Benefits: ============= - Consistent hover effects and animations - Responsive design with mobile-first approach - Accessibility features built-in - Performance optimizations (debouncing, lazy loading) - Modular and reusable components - Easy to customize and extend {% endcomment %}
