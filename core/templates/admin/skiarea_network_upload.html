📋 JSON Format Requirements

Your JSON file should follow this structure:

  • networks: Array of network objects
  • name: Unique name for the network (required)
  • season_pass_price: Price in CHF (optional)
  • members: Array of member ski areas
  • ski_area_id or ski_area_name: Reference to existing ski area
  • Dates: Use YYYY-MM-DD format

  "networks": [
    {
      "name": "TopCard",
      "members": [
        { "name": "Flims Laax Falera" },

        { "name": "Arosa Lenzerheide" }
      ]
    }
  ]
}
